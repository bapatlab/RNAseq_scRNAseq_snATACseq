# PAPER TITLE

This project contains the code used to generate the results in the paper "PAPER TITLE/DOI". Raw data is available on GSEXXX (single-cell RNA-seq data), GSEXXX (single-nucleus ATAC-seq data) and GSEXXX (bulk RNA-seq data).

This repository is organized by sequencing method. Each folder contains the code used to analyze the data and figures, including instruction for running the code and reproducing the results.
